# Implementation decisions

These are decisions taken while turning the proposal into a working system, with the reason for
each. The proposal's design is kept. Where we deviate, the change is a *configurable default*, chosen
so the system runs at $0 on an 8 GB laptop. The proposal's original choice remains one setting away.

| # | Decision | Reason | Switch back to the proposal's choice |
|---|---|---|---|
| D1 | The default LLM provider is **`offline`**: a deterministic, rule-based path in every agent (template queries per legal element, extractive IRAC drafting from verified passages). | $0 budget during development. A deterministic mode also makes the Citation Firewall and the approval gates fully testable. | `STARE_LLM_PROVIDER=anthropic` (Claude, `STARE_LLM_MODEL`/`STARE_LLM_FAST_MODEL`) or `openai_compat` with a free local Ollama server (`STARE_LLM_BASE_URL=http://localhost:11434/v1`). |
| D2 | The default database is **SQLite**. The schema is identical on PostgreSQL 16 + pgvector (vector column type and `<=>` search branch). | No Docker or Postgres on the laptop. | `STARE_DATABASE_URL=postgresql+psycopg://…` and `docker compose up db` (see `docker-compose.yml`). |
| D3 | The default dense embedder is **LSA** (TF-IDF + truncated SVD, 256 dims), fitted on the corpus. | No neural model download or CPU-heavy embedding on the laptop. | `STARE_EMBEDDER=fastembed` (bge-small) or `sentence_transformers` (e.g. LEGAL-BERT), then `stare index build`. |
| D4 | The default reranker is **lexical** (feature-based). | A cross-encoder is a neural model (heavy). | `STARE_RERANKER=cross_encoder`. |
| D5 | The corpus is a **curated seed** of real federal employment opinions (CAP static JSON + CourtListener) cached in `data/seed/raw/`, plus the statute and regulation text. | The CourtListener and CAP bulk files are many GB. | `stare ingest courtlistener-bulk DIR` / `stare ingest cap-bulk DIR` (importers are implemented and tested on fixtures). |
| D6 | The CourtListener API is the Gate 2/Gate 4 fallback **only**. It is anonymous unless `STARE_COURTLISTENER_TOKEN` is set (free account), and rate limited and cached. When it is unavailable, citations become `unresolved`, which is never exportable (NFR-06). | The free API has limits; the local index answers first. | Set a free token to enable the citation-lookup endpoint. |
| D6b | Gate 2 also consults the **Caselaw Access Project volume listings** on static.case.law (free, cached), which say exactly which case begins on each page of every published volume up to CAP's coverage end. A citation to a covered volume where no case begins on that page is blocked. A miss in CourtListener's *anonymous* search is treated as unresolved, not nonexistent, because that index can omit real opinions. Only the authenticated citation-lookup API proves non-existence. | No account is needed and there are no rate limits. It avoids falsely blocking real recent cases. | `STARE_CAP_LOOKUP_ENABLED=false`. Set `STARE_COURTLISTENER_TOKEN` for authoritative lookups of WL, neutral and post-2019 cites. |
| D7 | Gate 2 checks the **case name** as well as volume/reporter/page. | Several Mata fabrications point at real reporter pages that belong to other cases. Existence of a page is not existence of the cited case. | — |
| D8 | PII redaction uses **Presidio with spaCy `en_core_web_sm`** when installed, plus a regex layer. When Presidio is absent, the regex engine is used alone. A final guard refuses to send any prompt that still contains SSNs, emails or phone numbers. | The large spaCy model is 560 MB. The small one is enough with the regex layer, and the guard enforces NFR-03 for any provider. | `pip install -e '.[presidio]'` and `python -m spacy download en_core_web_lg`. |
| D9 | The raw uploaded file is **deleted after extraction** by default. Only redacted text is stored. | NFR-03: no raw client text in storage or logs. | `STARE_KEEP_RAW_UPLOADS=true`. |
| D10 | The plan gate and the memo gate are **LangGraph `interrupt()`s** with a SQLite checkpointer. A run survives a server restart. | Section 5.3.4: the graph cannot continue until an approval is recorded. | PostgresSaver when on PostgreSQL. |
| D11 | The general-purpose LLM baseline (Table 29) uses a **free** model (opencode `beam-free`) to answer the 100 gold questions without retrieval; `stare eval baseline --answers FILE` scores any model's answers with the same Firewall. Citations the free CourtListener API could not check because of its rate limit are reported as unresolved and separately. | $0 budget. | `stare eval baseline` with `STARE_LLM_PROVIDER=anthropic` (paid) or a local model. |
